# Pendências humanas — F0 (fundação)

## 1. Ligar o CI no GitHub

O workflow `.github/workflows/ci.yml` só roda depois que o repositório estiver no GitHub.

1. Crie o repositório (privado) em github.com.
2. `git remote add origin <url>` e `git push -u origin main`.
3. Em **Actions**, confira que o job `quality-gate` passou.
4. (Opcional) Em **Settings → Branches**, exija o job `quality-gate` antes de mesclar em `main`.

## 2. Segredos de produção

Os `.env.example` trazem valores de desenvolvimento (`change-me-...`). Antes de produção, gere
valores fortes e guarde-os só no servidor:

```sh
node -e "console.log(crypto.randomBytes(48).toString('base64url'))"
```

Use um valor diferente para cada: `JWT_ACCESS_SECRET`, `JWT_REFRESH_SECRET`, `EVOLUTION_API_KEY`
(o mesmo na API e no contêiner da Evolution) e `WHATSAPP_WEBHOOK_SECRET`. Troque também a senha do
Postgres (`POSTGRES_PASSWORD`).
