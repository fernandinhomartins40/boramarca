# Pendências humanas — B2 (entrada, WhatsApp e Ajustes do app)

## 1. Conferir as telas no aparelho

As telas foram comparadas com as referências só pela leitura do código. Num dev build
(`apps/mobile/README.md`, "Como rodar"), com `EXPO_PUBLIC_DATA_SOURCE=mock`:

1. Abra o app sem sessão: deve aparecer **Boas-vindas** (compare com `05-referencias/01-boas-vindas.jpg`).
2. **Começar** → digite qualquer celular que não seja `(11) 98765-4321` → código `123456` →
   cadastro rápido em 4 passos (compare com `02-cadastro.jpg`) → "Tudo pronto" → Conectar o WhatsApp.
3. Com `(11) 98765-4321` (conta de demonstração) você vai direto para a agenda.
4. Confira o preenchimento automático do código por SMS num Android real (o emulador não recebe SMS
   de verdade; o campo usa `autoComplete="sms-otp"` e, no iOS, `textContentType="oneTimeCode"`).

## 2. As quatro situações do WhatsApp (prompt 02)

Menu de desenvolvimento (Ajustes → Menu de desenvolvimento):

| Situação | Como ver |
|---|---|
| Sucesso | "Próximo pareamento conecta" → Ajustes → WhatsApp → Reconectar → escolha um jeito e espere ~9 s |
| Erro | "Próximo pareamento falha" → mesmo caminho → "Não deu para conectar" + "Tentar de novo" |
| Código expirado | "Próximo código de pareamento expira" → no código: "O código expirou" + "Gerar novo código"; no QR: renova sozinho |
| Desconexão depois | "Simular queda do WhatsApp" → banner vermelho fixo em todas as telas; toque para reconectar |

## 3. Parear um número real

Com `EXPO_PUBLIC_DATA_SOURCE=api` e a API real (agente D1), parear um WhatsApp de verdade pelos dois
caminhos (código de pareamento no mesmo celular; QR com outro celular). Só uma pessoa com o aparelho
consegue fazer isso.

## 4. iOS: abrir o WhatsApp

O botão "Abrir WhatsApp" usa `whatsapp://`. No iOS, o esquema precisa estar em
`LSApplicationQueriesSchemes` do `Info.plist` (pedido ao dono do `app.config.ts`, plano seção 11).
Conferir num iPhone depois do primeiro build no EAS.

## 5. Páginas do site

Ajustes → Conta abre `EXPO_PUBLIC_SITE_URL` + `/privacidade`, `/termos`, `/excluir-conta`, `/contato`
e `/#planos` (padrão `https://boramarca.com.br`). Antes de publicar, confirme que o domínio está no
ar com essas páginas (agente C5) e defina a variável por perfil no `eas.json`.

## 6. Exclusão de conta nas lojas

Conferido nas páginas oficiais em 14/11/2026 (Apple "Offering account deletion in your app",
diretriz 5.1.1(v); Google Play "Understanding Google Play's app account deletion requirements"):
o app inicia a exclusão dentro dele, explica o que é apagado e o que fica, confirma por código no
telefone da conta e avisa quando termina. Falta, por pessoa:

1. No Play Console → Conteúdo do app → Segurança dos dados: declarar que a exclusão existe e informar
   a URL `https://boramarca.com.br/excluir-conta`.
2. Na App Store Connect, na revisão, indicar o caminho: Ajustes → Conta → Excluir conta (a conta de
   demonstração `REVIEW_PHONE`/`REVIEW_OTP` da API serve para o revisor).
3. Revisão jurídica do texto "o que fica guardado" junto com a política de privacidade.
