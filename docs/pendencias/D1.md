# Pendências humanas — D1 (app ligado à API real)

## 1. Push no aparelho: `projectId` do EAS (precisa de conta Expo)

O app já registra o token de push (`src/lib/api/push.ts` → `POST /devices`) depois do login, quando a
permissão de notificação já foi dada. Sem `projectId` do EAS ele não registra nada (silencioso).

1. `npm i -g eas-cli` e `eas login` com a conta Expo do produto.
2. Em `apps/mobile`: `eas init` — grava o `projectId`. Ele precisa aparecer em
   `app.config.ts` como `extra: { eas: { projectId: '<uuid>' } }` (o `app.config.ts` é do agente D2;
   o `projectId` não é segredo).
3. Android: criar o projeto no Firebase, baixar `google-services.json`, enviar a chave FCM v1 ao EAS
   (`eas credentials` → Android → Push Notifications) e apontar `android.googleServicesFile` no
   `app.config.ts`.
4. iOS: chave APNs da conta Apple Developer enviada ao EAS (`eas credentials` → iOS).
5. Gerar um dev build, entrar com `EXPO_PUBLIC_DATA_SOURCE=api`, permitir notificações em
   Ajustes e reabrir o app: a tabela `devices` da API deve ganhar uma linha com o token
   `ExponentPushToken[...]`. Tocar em "Sair" remove a linha.
6. Pedir uma decisão pelo WhatsApp com o app fechado e responder Sim/Não na notificação.

## 2. Testar num aparelho com a API real

Só dá para fazer com aparelho/emulador (não feito nesta onda, por regra):

1. `apps/mobile/.env`: `EXPO_PUBLIC_DATA_SOURCE=api` e `EXPO_PUBLIC_API_URL` (emulador Android:
   `http://10.0.2.2:3333`; celular na mesma rede: `http://<IP do PC>:3333`).
2. `npx expo start --dev-client --clear`, entrar com a Marina (`+5511900000001`, `123456`).
3. Conferir: agenda carrega; responder uma decisão em outro aparelho/painel e ver a aba Decisões
   atualizar sozinha (WebSocket); desligar o Wi-Fi por 1 min e religar (reconexão); esperar 15 min
   com o app aberto (renovação de token sem sair).

## 3. Variáveis por perfil de build

`EXPO_PUBLIC_API_URL` precisa estar definida nos perfis `preview` e `production` do `eas.json`
(homologação e produção). Num build de release a fonte de dados é sempre `api`
(`resolveDataSource`), então sem essa variável o app mostra "Endereço da API não configurado".
